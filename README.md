# 🍣 OpenSauce POS

**OpenSauce POS** is a premium, open-source Point of Sale system designed with a focus on rich aesthetics, robust functionality, and ease of use. Built with a modern technology stack, it provides a powerful solution for small to medium-sized businesses looking for a professional checkout experience.

---

## 🚀 Core Features

- **🛍️ Feature-Rich POS Interface**: Optimized for speed with barcode scan support, quick-search, and category filtering.
- **📦 Inventory Management**: Track stock levels, manage categories, and handle complex product definitions with ease.
- **📊 Advanced Analytics**: Comprehensive sales reports and analytics to help you understand your business performance.
- **🖨️ Robust Peripheral Support**: Deep integration with thermal printers (USB, Network, Bluetooth), barcode scanners, and cash drawers.
- **🎨 Premium Aesthetics**: Stunning UI with support for both light and dark modes (featuring a signature neon green aesthetic).
- **🔒 Secure Access**: Multi-role user management (Admin/Cashier) with PIN-based authentication.
- **📑 Receipt Customization**: Detailed control over receipt layout, fonts, scales, and branding (logo/QR codes).
- **📱 Mobile Companion**: Support for linking mobile devices for remote operations.

## 💻 Tech Stack

- **Frontend**: React, TanStack Query, Radix UI, Lucide Icons
- **Backend/Desktop**: Electron, Express, Socket.io
- **Database**: SQLite (via Better-SQLite3 and Drizzle ORM)
- **Typing**: TypeScript
- **Styling**: Tailwind CSS / Vanilla CSS

## ⚙️ Quick Start

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-github-username/opensauce-pos.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev:electron
   ```
