7. Networking & Sync

Opensauce: POS features a robust Offline-First architecture.

How it Works

The system uses a local database (IndexedDB) to store all actions immediately, ensuring the app never freezes even if the internet goes down.

Sync Logic

  1. Action Queue: Every Create, Update, or Delete action (e.g., New Order, Update Product) is added to a SyncQueue in the local database.
  2. Online Detection: The app listens for the system's "Online" event.
  3. Processing:
    • When online, the app iterates through the queue.
    • It sends requests to the server (via Electron IPC or HTTP).
    • Successful syncs remove the item from the queue.
    • Failures are retried up to 3 times before being flagged.

Data Types Synced

  • Orders: Sales data is critical and prioritized.
  • Products: Inventory changes made offline will propagate when reconnected.
  • Customers: New customer profiles are queued.

8. Technical Manual

This section is for developers and system administrators maintaining the Opensauce codebase.

System Architecture

┌───────────────────────────────────────┐ │ Electron Wrapper │ ├────────────────────┬──────────────────┤ │ Backend Node.js │ Frontend React │ │ (Express Server) │ (Vite Renderer) │ │ [Port: 0] │ [Port: 5173] │ └─────────┬──────────┴─────────┬────────┘ │ │ SQLite DB IPC Bridge (Local Data Store) (Secure Comm.)

Key Components:

  • Electron (Main Process): Manages the application lifecycle. Spawns Node.js server as a child process.
  • Node.js Server: Express app handling API & Database (SQLite). Uses Port 0 (dynamic assignment).
  • SQLite: Local data store in user's AppData directory.

10. Troubleshooting Guide

Application Won't Start

  • Node Version: Ensure you are using Node.js v18+.
  • Reinstall: Run npm install.

Printer Not Printing

  • Check USB/Network connection.
  • Verify correct IP for network printers.
  • Use "Test Print" in Settings.

Focus: Market entry and core reliability.

  • Offline-First Architecture: Utilizing SQLite with Drizzle ORM to ensure the shop stays open during load shedding without needing internet.
  • Hardware Integration: Full support for thermal printers, barcode scanners, and cash drawers via secure Electron IPC handlers.
  • Role-Based Access: Clear distinction between Owner, Admin, and Cashier roles with protected owner accounts.
    • R2,500 once-off lifetime license "early bird" deal.

Phase 2: The Revenue Update (v1.7)

Focus: Turning the POS into a profit center for merchants via Value-Added Services (VAS).

  • VAS Integration: Partnering with South African aggregators (e.g., Freepaid) to sell Airtime, Data, and Electricity directly from the POS interface.
  • Voucher Sales: Adding support for digital vouchers (Netflix, Uber, Google Play, 1Voucher, Flash and more).
  • Security Hardening: Implementing Argon2/bcrypt PIN hashing and full API authentication to protect merchant wallets.
  • Database Optimization: Adding indexes for high-volume retailers to maintain sub-millisecond search speeds.

Phase 3: The Payment Revolution (v1.8)

Focus: Expanding payment flexibility for modern South African consumers.

  • Integrated Card Payments: Direct SDK integration with local providers for "one-tap" checkout.
  • Crypto "Scan-to-Pay": Enabling Bitcoin Lightning and Stablecoin payments via QR codes, with instant ZAR settlement for the merchant.
  • Database Encryption: Implementing encryption-at-rest to safeguard all business and customer data on the local device.
  • Audit Logging: Advanced event tracking to prevent internal shrinkage and simplify tax reporting.

Phase 4: The Mobile Expansion (v1.9)

Focus: Portability and multi-store management.

  • Android/iOS Launch: Utilizing the existing Capacitor/Mobile hooks to launch native apps for handheld "Smart POS" devices.
  • Multi-Store Sync: Activating the PostgreSQL sync feature (R99/month) to allow owners to manage multiple branches from one cloud dashboard.
  • Supplier Portal: A built-in module for one-tap ordering from wholesalers when stock levels hit their "low-stock" pulse.
  • AI Integration: Using AI to analyse sales data, provide informed decisions to boost sales, manage online orders via a chatbox (Whatsapp / Web).
